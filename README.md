# Anandhi Birthday Website — Updated Personal Photo Build

A mobile-friendly midnight-luxury birthday adventure for Anandhi, celebrating 28 October 2026.

## Included
- Seven passcode-locked entries: six memory chapters plus the final surprise.
- Tamil + English/Tanglish messages, countdown, interactive photo gallery/lightbox, celebration effects, and background music toggle.
- Only the personal photos supplied for Foodie, Sleep, and Cutie are included. No stock/sample photos are used.
- Dress-Up, Family, and Me & You chapters are ready for photos later; they show a message rather than using substitute images.
- Responsive on mobile and desktop.

## Passcodes
- Foodie Queen: `FOODIE28`
- Sleeping Beauty: `NAPQUEEN`
- Cutie Pie: `CUTIE28`
- Dress-Up Queen: `STYLE28`
- Our Family: `FAMILY28`
- Me & You: `AKKA28`
- Final Surprise: `LOVEANANDHI`

To change them, edit the `passcodes` object in `script.js`. These are playful surprise locks, not strong security: visitors can inspect the source of a static website.

## Music
For music, add an audio file you own or have permission to use as `assets/birthday-music.mp3`. The website does not bundle copyrighted music.

## Preview and publish on GitHub Pages
1. Extract this ZIP.
2. Open `index.html` in a browser to preview.
3. Upload `index.html`, `style.css`, `script.js`, and the full `assets/` folder to the root of your GitHub repository.
4. In GitHub, open **Settings → Pages**, select your branch and `/ (root)`, then save.

The countdown targets midnight at the start of 28 October 2026 in India Standard Time (IST).
